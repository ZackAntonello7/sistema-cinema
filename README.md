# Sistema de Gerenciamento de Cinema

Projeto desenvolvido para a disciplina de Engenharia de Software / Programação Orientada a Objetos.

## Objetivo

O sistema foi desenvolvido para auxiliar no gerenciamento de uma rede de cinemas, permitindo:

- Cadastro de filmes;
- Controle de sessões;
- Registro de público;
- Consulta de filmes em cartaz.

---

## Tecnologias Utilizadas

- Python
- SQLite
- GitHub
- UML

---

## Arquitetura

O projeto utiliza arquitetura em camadas:

- Model
- Controller
- Service
- Repository
